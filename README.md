Project name: FitLog

Short description:
FitLog is a dark, no-nonsense gym companion I built to make planning and tracking workouts simple. You pick a lift from the library, lock it into today's plan, and watch your minutes and calories add up as you go. No clutter, no distractions — just a clean way to log every set. 



Technologies used: 
Next.js (App Router)
React (Client & Server Components)
Tailwind CSS
Context API for global state management
react-icons / lucide-react for icons
Toast notifications for user feedback



5 key features of the project:
1.Workout Library — Browse all workouts in a responsive grid, each card showing the image, muscle group tags, equipment, duration, calories, and rating.
2.Today's Plan with a 5-Lift Cap — Add up to five exercises to your daily plan, track total minutes and calories, and mark each one as done when you finish it.
3.Save for Later — Bookmark any workout to revisit it afterward, separate from your active plan.
4.Sort & Filter — Sort your plan or saved list by duration, calories, or rating, so you can prioritize your session however you like.
5.Persistent Progress — Your plan and saved workouts stick around even after a refresh, so you never lose track of your session.
